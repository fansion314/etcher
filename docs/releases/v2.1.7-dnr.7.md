# Etcher 2.1.7 on dnr — release 7

This release requires dnr 0.4.3 and fixes macOS raw disk completion.

- dnr 0.4.3 uses the macOS fsync syscall for disk devices, avoiding the
  F_FULLFSYNC ENOTTY error that occurred after successful image verification.
- The Etcher worker closes descriptors even when a flush fails and continues
  to report the failure.
- Startup preserves dnr's restored user zoom. macOS retains a fixed 110%
  renderer layout baseline; Linux retains 100%. The old Electron viewport
  scaling heuristic remains disabled.
- Arch releases contain a directly installable pkg.tar.zst plus its SHA-256.
  The payload remains under /usr/lib/etcher-dnr. Build logs and provenance remain
  available as Actions artifacts.

Native macOS ARM64 and Linux x86_64 builds and SDK/package self-tests passed.
The packaged macOS worker wrote and verified 2 MiB on a disposable raw disk
image, flushed and closed successfully, and an independent read matched the
source. Physical USB flashing and ejection were not repeated.

The macOS layout was checked in a real WebView at the default user factor:
viewport and scroll size both remained 820 x 560 with all main buttons inside
the viewport. The combined Etcher shortcut/restart GUI check was interrupted
by the automation tool; dnr's own persistence regression passed separately.

Release 6's Arch build/tests passed, but publication stopped because its release
notes file was missing. This release adds a release-notes preflight check.

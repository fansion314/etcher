# Etcher 2.1.7 on dnr — release 5

This release fixes two desktop UI issues while keeping the Etcher 2.1.7 image
writer and the shared dnr runtime.

- On macOS, use dnr 0.4.2 native page zoom instead of the Electron renderer's
  CSS zoom. The previous adapter halved the content on Retina displays. The
  main window now uses a 1.1 application zoom factor, and dnr's user-wide zoom
  setting remains available.
- Save dismissal of the privacy notice in Etcher's persistent settings file.
  The page URL changes on each start, so browser localStorage could not retain
  that choice on macOS or Linux.
- Add the portable macOS ARM64 thin app release path using the shared Homebrew
  dnr runtime. The Linux source and prebuilt AUR packages remain named
  `etcher-dnr` and `etcher-dnr-bin`.

Native macOS ARM64 and Linux x86_64 builds and SDK/package self-tests passed.
Both desktop environments were checked by closing the notice and restarting
with the same settings directory. Physical USB flashing and eject were not
tested in this release validation.

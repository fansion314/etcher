# Etcher 2.1.8 on dnr — release 1

Synchronizes the DNR port with the exact upstream v2.1.8 release.

Upstream restores macOS utility entitlements and rebuilds drivelist for its
Electron sidecar runtime. The DNR port retains its shared runtime and separate
privileged worker, native groups, disk flush/error handling, and desktop
integration; it does not ship Electron or the upstream sidecar executable.

Source recipes pin the v2.1.8 commit and its archive checksum. Arch and macOS
release workflows build the DNR application and run SDK/package checks.
No local compilation was performed. Physical USB flashing and ejection are
outside the automated checks.

# Etcher 2.1.9 on dnr — release 1

Synchronizes the DNR port with the exact upstream v2.1.9 commit
`dbd6aaed37c4e844f7aed978db01d9f38680eff8`.

Upstream updates its Electron runtime and utility build to Node.js 24. The DNR
port keeps its shared runtime, privileged worker, native groups, disk flush and
error handling; it does not bundle Electron or the upstream sidecar executable.
The renderer adaptation now handles upstream's webUtils drop-path change while
preserving DNR's browser-to-host dropped-file import.

Source recipes pin the upstream commit and independently verified archive hash.
The self-contained source overlay is regenerated deterministically without a
local build; native package and GUI checks belong in release CI. Physical USB
flashing and ejection remain outside automated acceptance.

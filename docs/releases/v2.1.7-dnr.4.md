# Etcher 2.1.7 on dnr — Arch release 4

This release builds Etcher from the pinned 2.1.7 upstream source with the shared
dnr 0.4.1 runtime. The Arch package is named `etcher-dnr` and installs the
`/usr/bin/etcher` command, `etcher.desktop`, and the Etcher icon. The
`etcher-dnr-bin` AUR recipe installs the same checked GitHub Release payload.

- Remove the Linux exclusive-open shim now that dnr 0.4.1 preserves numeric
  `O_EXCL` flags. The SDK again uses its ordinary file-open path.
- Support macOS arm64 `.dnp` and thin `balenaEtcher.app` builds using the shared
  runtime. The local app uses macOS dialogs, disk utilities, and authorization.
- Keep the window title fixed during writes to avoid flicker; the dock badge
  continues to show progress.
- Use WebKitGTK as the installable Arch GUI backend. System CEF remains optional
  when installed separately.

The release workflow builds and tests the source AUR recipe in the official
Arch container, checks the `-bin` recipe against that exact package, and only
then publishes the archive, checksum, and build provenance. Headless checks do
not replace a physical USB write and eject test.
